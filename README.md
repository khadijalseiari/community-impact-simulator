# Community Impact Simulator

### Abu Dhabi Public Health Centre (ADPHC)

An interactive, bilingual web-based simulator that demonstrates how Community Health Sector initiatives can contribute to healthier environments and support population health across Abu Dhabi.

The simulator allows users to explore selected public health interventions and observe how each action transforms a virtual city in real time.

## About

The Community Impact Simulator highlights initiatives and program areas that support:

- Healthy nutrition
- Physical activity
- Preventive screening
- Occupational safety
- Health promotion
- Community wellbeing
- Healthier public spaces
- Healthier workplaces

Users can activate improvements across different areas of the city and view changes to the Community Health Score and related indicators.

## Featured Initiatives

## Local Use

Open `index.html` in a modern web browser. For the most reliable experience, serve the project through a local web server or GitHub Pages.

## GitHub Pages Deployment

1. Create a public GitHub repository.
2. Upload `index.html`, the `assets` folder, and `README.md`.
3. Open the repository settings.
4. Select **Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and the `/root` folder.
7. Save the settings.

The public address will follow this format:

```text
https://YOUR-USERNAME.github.io/adphc-community-impact-simulator/
```

## Disclaimer

This simulator is an educational and engagement tool. It is not an epidemiological model, population-level forecast, clinical decision-support tool, or official performance-reporting platform. Scores and visual changes within the simulator are illustrative and should not be interpreted as validated estimates of program impact.
